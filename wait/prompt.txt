Role: Senior Laravel Architect.
Context: Kita sedang membangun Website Profil Rumah Sakit. Project sudah terinstall Laravel 11.
Task: Buatkan Kode Migrations dan Models lengkap dengan Relasi (Eloquent Relationships).

Spesifikasi Tabel Database:
1. `specializations`: id, name, icon (string/nullable), timestamps.
2. `doctors`: id, specialization_id (FK), name, sip_number, bio (text), photo (string/nullable), is_active (boolean), timestamps.
3. `schedules`: id, doctor_id (FK), day (enum: Senin-Minggu), start_time, end_time, timestamps.
4. `services`: id, title, slug, category (enum: 'rawat_jalan', 'rawat_inap', 'penunjang'), content (longtext), image, timestamps.
5. `articles`: id, title, slug, content (longtext), thumbnail, status (enum: draft, published), published_at, timestamps.
6. `settings`: id, key (unique), value (text), type (text), timestamps.

Requirements:
- Berikan kode file Migration lengkap untuk semua tabel di atas.
- Berikan kode Model lengkap.
- Pada Model `Doctor`, tambahkan relasi `belongsTo` ke Specialization dan `hasMany` ke Schedules.
- Pada Model `Specialization`, tambahkan relasi `hasMany` ke Doctor.
- Gunakan $guarded = [] pada setiap model agar mass assignment aman di tahap dev.

Output: Hanya kode Migration dan Model.
